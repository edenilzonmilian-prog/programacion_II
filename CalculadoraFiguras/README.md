# Calculadora de Figuras Geométricas

## Descripción

Aplicación de consola en Java que calcula el área de diferentes figuras geométricas utilizando Programación Orientada a Objetos.

## Figuras implementadas

* Círculo
* Rectángulo
* Triángulo

## Cómo ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar la clase `Main`.
3. La consola mostrará el área de cada figura.
